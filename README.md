## 🚀 How to Download Files From This Repository

### 📱 On Mobile (Android/iPhone)

#### Method 1 — Download Entire Repository

1. Open the repository on GitHub
2. Tap the **Code** button
3. Select **Download ZIP**
4. Extract the ZIP file using:
   - ZArchiver
   - Files App
   - WinZip
   - RAR

#### Method 2 — Download a Single File

1. Open the file you want
2. Tap the **three dots (⋮)** or **Raw**
3. Choose **Download**
